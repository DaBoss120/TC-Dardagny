# Crédits

Ressources tierces utilisées sur le site du Tennis-Club Dardagny.

Ce fichier est la source de vérité : la page publique `/credits` reprend ces
mêmes entrées. Toute nouvelle ressource externe doit être ajoutée ici **et**
dans `src/pages/credits.php`.

## Modèles 3D

- "Tennis Ball" (https://skfb.ly/pBOuW) by amhyde is licensed under
  Creative Commons Attribution (http://creativecommons.org/licenses/by/4.0/).

  Utilisé dans la section d'accueil (`public/3d/tennis-ball.glb`). Le modèle a
  été modifié : la géométrie de la fourrure a été retirée et les textures
  réduites, afin d'alléger le fichier pour le web.
